SpecGuard

Diff two OpenAPI 3.0 or 3.1 specs and fail CI when the change breaks API clients. TypeScript library, CLI, GitHub Action, and Docker image — no hosted service required.

View on GitHub Get started

Quick start

npm install
npm run build
npx specguard check \
  --base fixtures/base.openapi.yaml \
  --head fixtures/head-breaking.openapi.yaml

What it checks

  • Removed paths, operations, and response status codes
  • Schema type, enum, and constraint changes with request vs response rules
  • New required parameters and properties
  • Local $ref resolution and allOf merging
